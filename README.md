# 🎓 Student Result Management System

A full-stack web application designed for educational institutions to efficiently manage, update, and publish student results. It features a secure Admin Dashboard for teachers and a dedicated Result Portal for students.

### ✨ Key Features
- **Admin Dashboard:** Analytics dashboard displaying total students, pass/fail ratio, and average marks.
- **Interactive Data Visualization:** Integrated **Chart.js** Doughnut chart for real-time result analytics.
- **CRUD Operations:** Easily Add, View, Edit, and Delete student records.
- **Secure Student Portal:** Two-step verification (Roll Number + Mother's Name) for students to securely view and print their Grade Cards.
- **Responsive Design:** Professional and clean UI with CSS gradients and hover effects.
